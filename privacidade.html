Política de privacidade

Sandálias de Pó · atualizada em 29 de outubro de 2026

Quem opera

Este site e o aplicativo descritos aqui são operados pelo dono do canal Sandálias de Pó, pessoa física, para uso no próprio canal. Contato: sandaliasdepo@gmail.com.

O que este site coleta

Nada. São páginas estáticas, sem formulário, sem cookies, sem analytics e sem rastreador de terceiros. Nenhum dado seu é registrado por nós quando você lê esta página.

O que o aplicativo acessa

O aplicativo roda no computador do operador e acessa apenas a conta do YouTube do próprio operador, mediante autorização dele via Google OAuth. As permissões pedidas são:

  • youtube.upload — enviar vídeos ao canal;
  • youtube.force-ssl — escrever e corrigir metadados dos vídeos do canal;
  • youtube.readonly — ler os dados do próprio canal;
  • yt-analytics.readonly — ler as métricas do próprio canal.

Não há usuários além do operador. O aplicativo não coleta, não solicita e não processa dados de espectadores nem de terceiros.

Onde ficam as credenciais

As credenciais OAuth e os tokens ficam apenas no computador do operador, em arquivos locais fora de qualquer repositório ou serviço de nuvem. Não são transmitidos a nenhum servidor nosso — não existe servidor nosso — nem compartilhados, vendidos ou cedidos a terceiros.

Retenção e exclusão

Os dados lidos da API (metadados e métricas do próprio canal) ficam em arquivos locais enquanto servirem à produção dos episódios, e são apagados junto com a pasta do projeto. O operador pode revogar o acesso do aplicativo a qualquer momento em myaccount.google.com/permissions, o que invalida os tokens imediatamente.

Uso de dados das APIs do Google

O uso que este aplicativo faz das informações recebidas das APIs do Google obedece à Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Serviços de API do YouTube

O aplicativo usa os Serviços de API do YouTube. Ao interagir com ele, você também está sujeito aos Termos de Serviço do YouTube e à Política de Privacidade do Google.

Mudanças

Alterações nesta política aparecem nesta página, com a data no topo atualizada.
